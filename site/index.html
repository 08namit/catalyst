Catalyst

Link two developers’ Claude Code sessions

Each developer runs a small per-project daemon. It keeps a signed, append-only event log and syncs it directly with the other laptop over an encrypted LAN connection. Shared goals, tasks, decisions, progress and questions reach the other developer’s Claude Code session through MCP tools and hooks, including when the two sessions run hours apart.

Install from source. Catalyst is not published to npm. Every command below runs from a clone of the repository.

1Prerequisites (both laptops)

  • Node.js ≥ 22.13 (24 LTS recommended). Check with node --version.
  • git
  • Claude Code (the claude command)
  • Both laptops on the same LAN, able to reach each other over TCP.

2Install from source (both laptops)

git clone <YOUR-CATALYST-REPO-URL> catalyst

<YOUR-CATALYST-REPO-URL> is a placeholder. Replace it with the URL of your Catalyst repository or fork.

cd catalyst && npm install && npm run build && npm link

npm link puts the catalyst command on your PATH. To remove it later, run npm unlink -g catalyst-coord.

3Pair a project

Each developer works in their own clone of the project (not of Catalyst). Each checkout counts as one participant.

Developer A (e.g. Tiam)

cd your-project
catalyst init --name "Tiam"
catalyst pair

This prints a single-use invite, valid for 15 minutes, that includes this laptop’s LAN addresses. Send it to Developer B over a channel you trust.

If the advertised address is wrong (VPN, several network interfaces), choose one with catalyst pair --host <ip>.

Developer B (e.g. Namit)

cd their-clone
catalyst join cat1_… --name "Namit"

Paste the full cat1_… invite printed by catalyst pair.

Then, on both laptops:

catalyst status

Compare the confirmation codes out loud or in chat. If they differ, stop: you are not connected to each other.

4Use it from Claude Code

claude

Start Claude Code inside the project. When Claude Code asks, approve the project MCP server named “catalyst”. The hooks then give each session a briefing when it starts, a one-line notice when the peer has published new updates, and an automatic record of commits and edits. The agent uses Catalyst tools to claim tasks, publish decisions and progress, and ask or answer questions.

5Check status

catalyst status

Shows the peer state (connected, unreachable, paused), the last sync, pending outbound events, sessions and the confirmation code.

catalyst doctor

Diagnoses common setup problems, such as the daemon, ports and the Claude Code integration, and suggests fixes.

catalyst dashboard

Opens the local dashboard in your browser. It is served only on 127.0.0.1 and receives a one-time token in the URL.

6Demo an outage

catalyst peer pause

This stops peer networking only. Both sessions keep working, and new events are saved locally and queued.

catalyst peer resume

On reconnect, the missed events are replayed in order. catalyst status shows the queue draining.

Network & firewall

  • Allow inbound TCP on the peer port shown by catalyst status. On macOS, allow incoming connections for node when prompted.
  • Both laptops must be on the same LAN or otherwise able to reach each other directly. Catalyst has no NAT traversal and no relay.
  • The local API and the dashboard listen on 127.0.0.1 only.

Trust model

Invite
The cat1_… invite is a bearer secret for 15 minutes. Anyone holding it can pair once. It is single-use and stored hashed.
Transport
TLS 1.2 with a pre-shared key (ECDHE-PSK, which gives forward secrecy), using a key derived for this pair and this project. Unknown identities are rejected.
Events
Every event is Ed25519-signed by its author and content-addressed by its SHA-256 hash. Tampered or forked events are detected.
Local access
The dashboard and API are loopback only. They require a per-start bearer token and enforce Host/Origin checks.
Limits
Task ownership is advisory, and conflicts are flagged rather than auto-resolved. Each developer still uses their own Claude model access.

Uninstall

Run these in each project:

catalyst uninstall claude

Removes the Catalyst MCP server, hooks and CLAUDE.md block from the project and keeps your other settings.

catalyst stop
rm -rf .catalyst

Deletes this project’s local event log, identity and keys. This cannot be undone.

To remove the CLI itself: npm unlink -g catalyst-coord, then delete the catalyst clone.
