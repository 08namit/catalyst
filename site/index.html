Catalyst

Two developers, many Claude agents, one task queue

Each developer runs one Claude Code session that can spawn several subagents. Catalyst gives every agent on both laptops a name (“Tiam / api”) and one shared queue of tasks, plus shared decisions, progress and questions. The two laptops sync directly over an encrypted LAN or VPN link. You install it once; after that you just talk to Claude.

Prerequisites (both laptops)

  • Node.js ≥ 22.13. Check with node --version.
  • Claude Code (the claude command).
  • Each person has their own git clone of the project.
  • Both laptops on the same network or VPN.

1Install (each person, once)

npm install -g github:08namit/catalyst && catalyst install

catalyst install checks your setup and registers Catalyst with Claude Code for all your projects.

2Connect (once per project)

Person A (e.g. Tiam)

Open Claude Code in the project and say:

set up Catalyst and invite my teammate

Claude replies with an invite starting with cat1_. Send it to person B privately. It works once, for 30 minutes.

Person B (e.g. Namit)

Open Claude Code in your copy of the project and say:

join Catalyst with cat1_…

Both Claudes show a confirmation code. Check that they match. If they differ, stop and make a new invite.

Then restart Claude Code once on each laptop so the Catalyst hooks load, and commit the files Catalyst added (.mcp.json, .claude/settings.json, CLAUDE.md, .gitignore).

3Build

Tell your Claude what to build, for example:

Build the notes app. Split it into tasks, post them to Catalyst, and use 3 subagents to work through the queue.

Claude posts the tasks to the shared queue and spawns subagents. Each takes the next ready task, finishes it and takes another. Agents on your teammate’s laptop take tasks from the same queue. Agents waiting for an answer use wait_for_updates instead of stopping.

Check status

catalyst

A few plain-English lines: who you are connected to, agents working, the queue, conflicts and one suggested next step. Or ask Claude “what’s the Catalyst status?”.

catalyst doctor

Diagnoses common setup problems and suggests fixes.

catalyst dashboard

Opens the local, read-only dashboard: agents, queue, decisions, questions and delivery. Served only on 127.0.0.1.

Pause and resume

Say “pause Catalyst sync”. Both sides keep working; new updates are saved and queued. Say “resume Catalyst sync” and the missed updates replay. If both sides changed the same decision or took the same task meanwhile, both versions are kept and flagged as a conflict for you to resolve.

Network & firewall

  • Allow inbound TCP on the peer port shown by catalyst status. On macOS, allow incoming connections for node when prompted.
  • Both laptops must be on the same LAN or VPN and able to reach each other directly. Catalyst has no NAT traversal and no relay.
  • The local API and the dashboard listen on 127.0.0.1 only.

Trust model

Invite
The cat1_… invite is a bearer secret for 30 minutes. Anyone holding it can pair once. It is single-use and stored hashed.
Transport
TLS 1.2 with a pre-shared key (ECDHE-PSK, which gives forward secrecy), using a key derived for this pair and this project. Unknown identities are rejected.
Events
Every event is Ed25519-signed by its author and content-addressed by its SHA-256 hash. Tampered or forked events are detected.
Local access
The dashboard and API are loopback only. They require a per-start bearer token and enforce Host/Origin checks.
Agents
All agents of one person run in the same Claude session and are trusted equally. Their names keep work apart; they are not a security boundary.
Limits
Task ownership is advisory, and conflicts are flagged rather than auto-resolved. Each developer still uses their own Claude model access.

Uninstall

Run these in each project:

catalyst uninstall claude

Removes the Catalyst MCP server, hooks and CLAUDE.md block from the project and keeps your other settings.

catalyst stop
rm -rf .catalyst

Deletes this project’s local event log, identity and keys. This cannot be undone.

To remove Catalyst from Claude Code: catalyst uninstall. To remove the command itself: npm uninstall -g catalyst-coord.
